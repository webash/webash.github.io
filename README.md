# webash.github.io — responsive starter

This repo was updated to include a mobile-first responsive layout and basic Jekyll scaffolding.

Quick checks:

- Serve locally: `bundle exec jekyll serve --livereload` (requires Ruby and Bundler)
- Or preview by opening `index.html` in a browser for static checks.

What I changed:

- Added `_layouts/default.html` and `_includes` for header/footer
- Converted `index.html`, `404.html`, and one sample post to use the layout
- Rewrote `assets/css/styles.css` with mobile-first responsive rules

Next steps you might want:

- Tweak `assets/css/styles.css` to match your new design assets
- Add site images and fonts under `assets/`
- Convert more posts/pages to use Jekyll front matter
